# V2.2 版本日志 —— Electron 打包发布版（免安装单文件）

> 状态：✅ 已打包，功能稳定，可对外分发
> 本版包含：`DeepSeekBalanceMonitor-2.2.0-portable.exe`（单文件免安装，双击即用）

## 这个版本是什么
在 V2.1（Electron 开发版）基础上完成的**正式打包版**。
Electron 自带 Chromium 渲染内核，**不依赖系统 WebView2**——
朋友电脑直接双击 exe 即可运行，不会再出现旧版“只有托盘、唤不出窗口”的问题。

## 实现了什么（功能清单）
- 余额实时查询（DeepSeek 官方接口），多账号切换，账号与设置存本机配置
- 圆环百分比（自定义“满格金额”），两次刷新间消耗/增加统计
- 右上角图钉：置顶到最高层（screen-saver 层 + moveTop 双重保障），再点取消
- 窗口拖动移动（空白处拖动），缩放使用系统原生边缘缩放（跟手无追赶）
- 系统托盘（单击唤出；右键菜单：显示/隐藏/退出）
- 单实例（重复启动只唤出已有窗口）、渲染崩溃自动重载
- 界面整窗深色填充、流式自适应布局

## 与 V2.1 相比的更改
- 首次完成 electron-builder 免安装打包（portable 单 exe）
- 置顶层级从 floating 改为 screen-saver，修复“钉得越来越低/被全屏和其他置顶窗口压住”
- 钉子切换重写：主进程状态唯一权威 + 状态推送 + 防抖，修复无法取消与误触相邻按钮
- 缩放改为系统原生边缘缩放，去掉自绘缩放层（修复内容追赶边框的弹性感）

## 出过错 / 解决的坑
- electron-builder 解压签名组件因系统权限无法创建符号链接 → 配置 `signAndEditExecutable: false` + 禁用自动签名解决
- package.json 曾被写入 BOM 导致 JSON 解析失败 → 改为无 BOM UTF-8 重写
- 打包前需用国内镜像下载 electron / nsis 等组件

## 完成度
- 功能：约 95%（缺：代码签名证书、开机自启、桌面通知等加分项）
- 稳定性：Electron 自带内核，冒烟测试通过；建议在 1~2 台朋友电脑真机验证
- 运行：双击 exe；配置与日志在 `%APPDATA%\DeepSeek余额监控\`
