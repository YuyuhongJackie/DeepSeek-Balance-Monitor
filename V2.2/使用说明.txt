# V2.2 使用说明（给朋友）

1. 双击 DeepSeekBalanceMonitor-2.2.0-portable.exe 即可运行，无需安装。
2. 首次使用：点右上角齿轮 → 粘贴你的 DeepSeek API Key（sk- 开头）→ 添加并切换。
3. 账号与设置只保存在自己电脑（%APPDATA%\DeepSeek余额监控\），不会上传。

常用操作：
- 移动窗口：按住窗口空白处拖动
- 缩放窗口：拖窗口边缘 / 四角
- 置顶：点右上角图钉（深蓝实心 = 已置顶），再点取消
- 收进托盘：点右上角 −；从托盘唤出：单击托盘图标
- 退出：点右上角 ✕，或右键托盘图标 → 退出

注：exe 未签名，Windows 若提示“未知发布者”，点“更多信息 → 仍要运行”即可。
