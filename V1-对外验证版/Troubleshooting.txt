# V1 对外验证版 · 排查说明

## 这是什么
旧版程序（V1）的对外测试副本，用于定位“在别的电脑上运行不正常”的问题。
本文件夹没有改动仓库里的 V1 原文件。

## 请按顺序操作（全部双击即可，不需要命令行知识）
1. 双击 run.bat
   - 它会检测 WebView2 运行库：没有就尝试自动下载安装，有就直接启动程序。
   - 请把黑色窗口里显示的内容截图。
2. 如果程序没正常出现，再双击 collect-report.bat
   - 它会在【桌面】生成一个 “DeepSeek report” 文件夹。
   - 请把该文件夹压缩成 zip 发给开发者。

## 开发者需要朋友补充的信息
1. Windows 版本、是不是 64 位（report 已自动收集）
2. 是否安装过 Microsoft Edge / 能否打开网页
3. run.bat 窗口显示了什么（截图）
4. 双击程序后：托盘有没有图标？点一下/右键分别什么反应？
5. 杀毒软件是否拦截过？

## 常见原因
- 缺少 WebView2 运行库（Win10/精简系统常见）→ run.bat 会自动安装
- 安全软件拦截未签名程序 → 右键 exe → 属性 → 解除锁定 / 添加信任
- 系统过旧 → 需要 Windows 10/11 64 位

## 终极方案
V2.1（Electron）自带渲染内核，不依赖 WebView2，打包后朋友电脑双击即可运行。
