# V1 版本日志 —— 稳定版（Python + pywebview）

> 状态：✅ 已完成、可用（不再维护，被 V2.1 Electron 取代）
> 本版包含：`main.py`（后端）、`balance-widget.html`（界面）、图标、`DeepSeek余额监控-v1.0.exe`（免安装成品）、打包配置

## 这是什么版本

基于 **Python + pywebview（Windows WebView2 渲染）** 的完整可用版本。
是整条旧路线的“地基”和可交付版本；V2 的所有试验都从它上面长出来，
但它自己保持稳定、可正常使用。

## 实现了什么

- 桌面无边框小窗口，整窗填充深色渐变（无黑角），底部显示余额与按钮。
- 查询 DeepSeek 官方余额接口（`GET /user/balance`），实时显示余额。
- 圆环百分比：百分比 = 当前余额 ÷ 用户自定义“满格金额”。
- 多账号管理：粘贴多个 API Key、一键切换、备注名；账号与满格金额保存在本机配置文件。
- 两次刷新间差额统计：显示本次相比上次消耗/增加了多少钱、占满格百分比，按账号分别记忆。
- 启动即显示窗口；最小化进系统托盘；托盘单击/双击唤出、右键菜单退出。
- 自定义 Win32 托盘（原 pystray 右键菜单在部分环境失效，故自写）。
- 单实例互斥：重复打开 exe 只唤出已有窗口，不重复开进程。
- 置顶、窗口位置记忆等基础体验项（细节随迭代有所调整）。

## 相比早期草稿的更改（重要）

- 界面从“演示数据”原型接入真实 API，并把数据保存在本机而非浏览器缓存。
- 修复“每次启动都要重新登录”：pystray/pywebview 的桥接注入很慢且 `api` 方法晚于基础对象注入，改为等待 `api` 就绪；注入器会递归展开公开属性导致极慢，故把窗口对象改成私有属性。
- 修复“启动后百分比显示错误数字”：两个数字动画共用同一个动画 ID，第二个会取消第一个，改为每个元素独立动画 ID。
- 修复“点了托盘唤不醒窗口”：pywebview 的 `show()` 在“启动即隐藏”场景失效，改直接用 Win32 `ShowWindow` 控制窗口。
- 修复“窗口四角有黑边”：卡片从“圆角卡片居中”改为铺满整个窗口。
- 增加“启动卡死自动重启”看门狗与“运行时心跳自愈”（页面就绪后定时探测 UI 线程，无响应自动重启）。

## 出过错 / 踩坑记录

1. 浏览器直连接口的跨域：实际 DeepSeek 服务器回显允许任意来源，直连可行；桌面版仍走 Python 后端。
2. WebView2 在该电脑上间歇性“未响应”：加 `--disable-gpu` 等软件渲染参数 + 自动重启看门狗缓解，无法根治（这是换 Electron 的根本原因）。
3. pystray 右键菜单不显示 → 自写 Win32 托盘。
4. 单文件 exe 被旧实例锁定无法覆盖 → 先退出旧进程再替换。

## 完成度

- 功能完成度：约 95%（缺失项：开机自启、桌面通知/声音提醒等“加分项”未做）。
- 稳定性：在 WebView2 正常的机器上可用；在开发者这台电脑上偶发渲染层无响应（已用自动重启缓解）。

## 结论

V1 是旧路线的“可用交付版本”，保留它主要是为了备份一个能跑的稳定实现；
后续不再在此路线上投入，界面与设计会迁移到 V2.1（Electron）。
