DeepSeek 余额监控 · 免安装版
============================

【这是什么】
一个桌面小工具：实时显示你的 DeepSeek API 账户余额，
余额低于设定值时卡片变红提醒，支持多个账号一键切换。
免安装，双击即可运行。

【使用方法】
1. 双击 DeepSeek余额监控.exe
2. 第一次使用：点卡片上的账号条（或右下角齿轮）打开设置
3. 粘贴你的 DeepSeek API Key（sk- 开头），备注名随意 → 添加并切换
4. 之后每次打开都会自动读取已保存的账号，无需重复输入

【获取 API Key】
打开 platform.deepseek.com → 注册/登录 → API Keys → 创建新 Key

【常用操作】
- 刷新余额：点右下角刷新按钮，或右键卡片 → 立即刷新
- 百分比含义：圆环百分比 = 当前余额 ÷ 满格金额
  （满格金额默认 100，可在设置里改成你习惯的数值）
- 多账号：设置里可添加多个 Key，点任意账号即可切换
- 置顶：右键卡片 → 置顶窗口，让小组件盖在其他窗口上面
- 移动：按住卡片空白处拖动
- 退出：右键卡片 → 退出，或 Alt+F4

【常见问题】
- 运行被 Windows 拦截：点"更多信息"→"仍要运行"。
  这是未签名程序的正常提示，非病毒。
- 杀毒软件报警：添加信任即可（PyInstaller 打包的程序常见误报）。
- 双击没反应：需要 Edge WebView2 运行库（Win10/11 一般自带，可搜索安装）。
- 启动后看不到窗口：程序默认藏在右下角系统托盘里，点托盘图标可打开/退出。

【隐私说明】
你的 API Key 只保存在自己电脑上
（%APPDATA%\DeepSeekBalanceMonitor\config.json），不会上传到任何地方。
请勿把该配置文件发给别人。
